Control con trazabilidad

Las acciones y accesos a la bóveda quedan registrados sin revelar contraseñas.

Las credenciales se cifran con AES-256-GCM. Consultarlas requiere confirmar tu contraseña de administrador. Las claves de usuarios de AD no se guardan automáticamente aquí.

Política de generación

Se aplica a las nuevas claves generadas por este gestor.

Entre 15 y 64 caracteres. No modifica las claves existentes.

Alcance de la política

La generación se realiza en el servidor mediante aleatoriedad criptográfica.

El registro de huellas evita volver a generar una contraseña emitida por esta instancia. No compara contraseñas actuales de Windows/AD ni las generadas por otras aplicaciones.

Configura también la política de contraseña de Active Directory para cubrir cambios realizados fuera del gestor.

Si Windows o AD exige una longitud o restricciones superiores, la generación debe ajustarse a esa política.
