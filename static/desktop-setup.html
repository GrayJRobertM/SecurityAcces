Metakampo Access

APLICACIÓN DE ESTE SERVIDOR

Configura tu entorno

La bóveda y la configuración quedan protegidas para este equipo y esta cuenta Windows.

Administra las cuentas Windows de este servidor, incluso en WORKGROUP. Abre el programa como administrador. Las cuentas integradas, administradores y la cuenta actual están protegidas. Cada entorno conserva sus propios datos.

Directorio autorizado

Se usa la identidad Windows que abre el programa. Esa cuenta debe tener permisos delegados en la OU o contenedor indicado. Admite CN=Users o una OU; consulta solo esa ubicación y sus descendientes. Domain Controllers normalmente contiene equipos.

Certificados para RDP (opcional)

Los clientes preparados funcionarán solo en este servidor y con esta cuenta Windows.

Administrador de la aplicación

Usuario: admin. Elige libremente una contraseña, sin longitud mínima ni combinación obligatoria.

Después de configurar, activa el servicio una sola vez con la contraseña Windows del propietario. Metakampo seguirá disponible al cerrar las ventanas y las sesiones.
